Mixed Language Example

Hello! नमस्ते! Bonjour! - This demonstrates how UTF-8 encoding allows us to display multiple languages on the same page.

Technical Note: The <meta charset="UTF-8"> declaration in the head section ensures that all characters from different languages are properly encoded and displayed correctly in web browsers.
