URI Encoding Examples

This page demonstrates URI encoding, which is used to safely include special characters in URLs.

Original URL with Special Characters

The following URL contains spaces and special characters that need to be encoded:

https://example.com/search?query=HTML & CSS

Encoded URL

Here's the same URL with proper URI encoding (spaces become %20):

https://example.com/search?query=HTML%20%26%20CSS

Click the link below to see URI encoding in action:

Search for "HTML & CSS" (Encoded URL)

Common URI Encoding Examples

  • Space: %20
  • Ampersand (&): %26
  • Plus sign (+): %2B
  • Question mark (?): %3F
  • Hash (#): %23
  • Percent (%): %25

Note: URI encoding ensures that special characters in URLs are properly transmitted and interpreted by web servers and browsers.
