Exploring Linear and Radial Gradients

Linear Gradient Background

This section demonstrates a linear gradient that transitions from top to bottom. The gradient creates a smooth color blend from one color to another, creating a visually appealing background effect.

Linear gradients can be customized with different angles and multiple color stops to create various effects and visual depth.

Radial Gradient Background

This section uses a radial gradient that emanates from the center, creating a circular or elliptical color transition. Radial gradients are perfect for creating spotlight effects or drawing attention to central content.

Notice the background-attachment: fixed property applied here, which creates a parallax-like effect as you scroll through the page.

Angled Linear Gradient

This section shows a linear gradient at a 45-degree angle, demonstrating how gradients can be oriented in different directions for creative layouts.
