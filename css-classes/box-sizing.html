Box-Sizing Comparison

Understanding content-box vs border-box

Default (content-box)

With content-box (default), padding and border are added to the total width. The total width = width + padding + border

Width: 300px

Padding: 30px

Border: 5px

Total: 370px

Border-Box

With border-box, padding and border are included in the width. The total width = width (includes padding and border)

Width: 300px

Padding: 30px

Border: 5px

Total: 300px
