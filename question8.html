Understanding the CSS Box Model

Default Box Model (content-box)

Margin
Border
Padding
Content

In the default box model, width and height apply only to the content area. Padding and border are added to the total size.

Border-Box Model

Margin
Border
Padding
Content

With box-sizing: border-box, width and height include padding and border. The total size remains constant.
